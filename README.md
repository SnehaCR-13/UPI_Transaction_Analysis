# UPI Transaction Analysis

## Project Overview

This project focuses on analyzing UPI transaction data to understand transaction patterns, customer and merchant risk, fraud indicators, and overall transaction behavior.

The project follows an end-to-end data analytics workflow involving data preparation, database management, analysis, visualization, and reporting. SQL and Python were used for data processing and analysis, while Power BI and Tableau were used to create interactive visualizations and dashboards.

## Objectives

- Analyze UPI transaction patterns and trends.
- Identify potential indicators of fraudulent transactions.
- Analyze customer and merchant risk scores.
- Perform data cleaning and validation to ensure data quality.
- Generate meaningful insights from transactional and related datasets.
- Present findings through interactive dashboards and visualizations.

## Tools & Technologies

- **SQL / MySQL** – Database creation, data management, querying, validation, joins, aggregations, and analysis.
- **Python** – Data importing, cleaning, preprocessing, statistical analysis, and visualization.
- **Power BI** – Addition of calculative measures and business visualization.
- **Tableau** – Interactive data visualization and fraud risk analysis.
- **Microsoft Excel** – Data preparation, validation, and supporting analysis.
